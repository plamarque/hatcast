# Documentation V1 (legacy)

**Périmètre :** client **Vue 3 + Firebase** sous [`legacy/`](../../legacy/) (Firestore, Auth, Cloud Functions, PWA actuelle en production sur Firebase Hosting).

**Important pour les agents :** cette documentation décrit le comportement et l’implémentation **V1**. Elle sert de **référence** (compréhension du domaine, UX, patterns) pour construire la **V2** ; elle **ne documente pas** la stack V2 (`apps/web/`, `services/api/`, Neon, Cloud Run). Pour la V2, voir [`docs/v2/README.md`](../v2/README.md) et les docs racine alignées (ARCH, PLAN).
