Cette page est conservée pour référence. Dans l’application, l’aide s’affiche sous forme de **5 étapes illustrées** (carrousel « Comprendre les pourcentages de tirage »).

## En une phrase

Les % décrivent vos **chances relatives** avant le tirage — ce n’est pas une garantie, le hasard reste décisif.

## Les 5 idées clés

1. **Sac de papiers** — chaque candidat dispo est un nom dans le sac.
2. **Plusieurs places** — plusieurs tirages sans remettre le papier (d’où des % plus élevés qu’une simple division).
3. **Équité saison** — les papiers grossissent ou rétrécissent selon l’historique sur le rôle.
4. **Ce que vous voyez** — largeur et couleur du pool = niveau de chance.
5. **Plusieurs rôles** — on recommence pour chaque rôle du spectacle.

## Détail par personne

Sur **Équipe** ou **Dispos → Tous**, touchez un **segment du pool** (ou le **%** sur certains écrans) pour ouvrir la fiche **« D’où vient ce % ? »** : classement dans le pool, chance de base, écarts en points, chance finale. Lien **« Comprendre le tirage en général »** → carrousel.
