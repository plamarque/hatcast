Comprendre les pourcentages de tirage

Le tirage reste aléatoire — les % indiquent seulement qui part avec plus ou moins de chances.

@switch (currentSlide()) { @case (0) {

Pour choisir qui joue, HatCast fait un peu comme si on mettait tous les noms des personnes disponibles sur des bouts de papier… dans un sac.

} @case (1) {

Si tout le monde partait à égalité, chacun aurait à peu près places ÷ candidats de chances — par ex. 5 places pour 8 candidats ≈ 63 % chacun (pas 12 % : il y a plusieurs tirages).

} @case (2) {

Pour répartir les rôles sur la saison, HatCast agrandit ou rétrécit les papiers selon le nombre de fois où chacun a déjà joué ce rôle.

} @case (3) {

Au moment du tirage, un gros papier a plus de chances d’être sorti qu’un petit — c’est ce que reflètent les % affichés.

} @case (4) {

On tire autant de fois qu’il y a de places pour le rôle, sans remettre le papier sorti. Puis on recommence pour chaque rôle du spectacle.

} }
