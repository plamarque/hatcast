Reference: the approved Advent board and confirmation reference in the Advent UX imports. Captures were taken on the real offline stack using fictional seed accounts at 390 CSS px; browser fixture tests also exercise 320–1280 px.

| Surface | Observed starting point | Change in this work |
| --- | --- | --- |
| Discovery | Recognizable elf and gift on a mostly flat pale scene, with simple text-symbol decorations. | Illustrated snowy night village behind the authorized elf, warm lights and a red rounded invitation. |
| Question | Readable choices and round portrait, but no illustrated framing and a plain action. | Existing real choices remain; scoped winter foliage and a snowy red primary action extend the illustration language. |
| Confirmation | Small portrait and cream panel, without the large joyful character or rich reference composition. | Large fictional generic elf with gift, personal portrait retained as a small badge, snowy panel and red primary action. |

| Calendar and ranking | Existing gift grid and readable ranking; spare surrounding scene. | Existing information and state projections retained, with shared winter framing and primary-action treatment. |
| Christmas | Existing Santa and present over plain cream. | Existing illustration and score retained with shared snowy foliage and primary action. |
| Missing content and error | Text and retry controls on plain background. | Generic encouraging elf and shared winter framing; actions and messages remain real controls and text. |

The new moods are **generic artwork**, not new facial expressions of each private personalized portrait. Individual likenesses continue to use existing authorized portrait delivery. The discovery, question, confirmation, incorrect result, calendar and Christmas were inspected on the real isolated stack; the correct result and the other calendar widths were inspected using browser fixtures. Error and absence were visually inspected with intercepted fictional responses in an isolated browser test, not against a real server failure. No screen-reader session or numerical contrast audit was run, per the approved story boundary.
