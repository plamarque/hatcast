# Vocabulary and concept boundaries

| Existing French label | Common label | Boundary |
|---|---|---|
| Troupe | Groupe | Existing organization, memberships and seasons. |
| Spectacle | Événement | A seasonal activity such as a match or training. |
| Format | Type | Role defaults and confirmation choice; distinct from category. |
| Compo / Composition | Sélection | People and roles chosen manually or through enabled draw. |
| Ma troupe trigger | Resolved group name and icon/logo | Group, season and statistics share an authorized context. |

Common labels apply throughout the interface. Groups may customize the four
common concepts; their role names are catalog entries. Saison, Dispos and Équipe
are not renamed by implication. Group-specific surfaces use group labels; shared
multigroup chrome uses common labels. Cover accessible names, French grammatical
forms, help, notifications, messages and error/empty states. Common forms provide
fallback; preserve user-authored content and audit snapshots.

| Concept | Meaning |
|---|---|
| Availability | Declared ability/willingness for offered roles: Dispo / Pas dispo. |
| Selection | Organizer assignment, manual or through an effectively enabled draw. |
| Sélectionné | Commitment established by organizer validation without a member confirmation. |
| Confirmation | Recorded later response to an offer, by a member or authorized proxy. |
| Withdrawal | A participant leaves a commitment; the role becomes available. |
| Actual attendance | What happened; not proven by availability, selection or confirmation. |
| Event type | Group-owned definition of default role needs and confirmation choice. |
| Category | Independent history/statistics compartment, retained without draw. |
| Probability color | Chance indication, hidden when the event disables draw. |
| Participation color | Availability, selection, confirmation or withdrawal state, retained. |
| Group default | Current group or type configuration used for new events. |
| Effective event rule | Behavior resolved for an event and preserved after defaults change. |
| Archived catalog definition | Not offered for new event needs; remains usable for existing references and event needs. |

Simple intended-presence mode and linked event series are deferred pending a
confirmed need; these are not active participation concepts for this scope.
