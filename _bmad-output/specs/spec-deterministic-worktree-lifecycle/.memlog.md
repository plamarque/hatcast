- (direction by user) Make worktree management systematic and deterministic instead of relying on agents to create units manually.
- (fact) bmad-loop external-worktree mode requires an existing adjacent feat/{story-key} worktree; pre_story and pre_bundle hooks run before that check.
- (constraint by user) Integration and cleanup must also be managed, while the existing explicit human review and approval gate remains mandatory.
- (fact) scripts/v2/story-branch.sh start is the established idempotent unit creation command; integrate already verifies clean v2, push, remote ancestry, then performs local cleanup only after success.
- (constraint) No automation may approve a human review, merge, push, or delete a worktree on its own.
- (event) Coherence validation passed: preparation, handoff, approved integration, and build launch each have testable success conditions and a separately bounded story.
- (event) Preservation validation passed: explicit human approval, existing story-branch integration safeguards, external-unit preservation, and the Epic 21 operator-gate sequencing remain constraints rather than automation.
- (direction by user) When a build or Loop reaches human validation successfully, interrupt the operator only with a concise structured smoke guide that recalls the story and gives executable steps; the operator should be able to answer smoke OK.
- (decision) Keep the machine-readable smoke guide as an internal validation contract, but render a human-readable Markdown smoke card with story purpose, URL, prerequisites, numbered actions, expected observations, and an exact smoke OK response.
- (constraint) An exact smoke OK confirmation is evidence of completed human smoke only: it must trigger current-state revalidation and remain distinct from code-review approval and integration authorization.
- (decision) Extend story 21-7 with the human-readable smoke-card and confirmation bridge; retain its existing spec and done checkpoints.
- (event) Coherence validation passed: the smoke card is a testable human surface, exact smoke confirmation has a bounded evidence effect, and integration authority remains separate.
